# Tiff's birthday music video

Commissioned birthday music video for Tiff (from Adrian), set to "My Whole Supply". The storyboard lives in `storyboard/` (`data.js` is the source of truth; `index.html` renders it). The animatic is rebuilt with `storyboard/animatic/build.sh`; a single-section animatic from the locked renders is `node storyboard/animatic/section.js V1` (480p, song timing), and the full film is `node storyboard/animatic/section.js ALL` (**1080p from 11 October, user**; a second argument sets another height). `storyboard/animatic/plan.js` decides what each shot plays (clip, stills, re-cut or full-frame overlay) for both the ffmpeg animatic and the After Effects export. Extra frames are named `<ID>b/c/d` (cuts or push-in steps) and `<ID>-end` (start+end shots); `gen.of` reuses another shot's frames (choruses, IN-01 = PR-01) and `gen.frames` re-cuts a list of frames (OU-04); `renders/wip.txt` lists frames still to adjust. All 74 shots have frames as of 10 October. **On-screen text (10 October):** `storyboard/overlays/spec.js` lists every overlay (speech bubbles, chat, role cards, GPS readouts, signs, quiz card, scorecards, labels, end card) per frame name; `node storyboard/overlays/render.js [frame…]` renders transparent 1920×1080 PNGs to `overlays/png/` (and previews over the renders to the git-ignored `overlays/preview/`). The animatic composites them automatically (`NOTEXT=1` turns them off); OU-07's end card is the overlay itself. **Clips (11 October):** Kling clips live in `storyboard/animatic/clips/<SHOT-ID>.mp4` (git-ignored; `storyboard/animatic/clips.json` maps shot ID to Higgsfield result URL, and `node storyboard/animatic/fetch-clips.js` downloads any that are missing; add each newly locked clip there) and replace that shot's stills in the animatic; a `gen.of` shot uses its source's clip. Start+end clips are sped up to fit the shot so the end frame lands; the rest play at real speed and are cut at the shot's end (user's choice). Text overlays stay on clip shots as placeholders; tracked ones (EXIT 41, V2-10 scorecards) drift and get redone in After Effects. **After Effects (11 October, user wants the edit and the text editable in AE):** `storyboard/ae/` holds `build-animatic.jsx` (run in AE via File > Scripts > Run Script File) plus `animatic-data.jsxinc` and `graphics/`, both written by `node storyboard/ae/export.js`; re-run the export whenever data.js, the renders, the clips or overlays/spec.js change. The script builds a 1920×1080 24 fps edit comp on the song timeline with one precomp per shot (1 s head and 2 s tail handles for retiming; clips time-remapped so speed is two keyframes; stills with a push-in), and every overlay item as a null with its graphic PNG and live AE text layers (fonts: Baloo 2, Nunito, Overpass, Patrick Hand). See `storyboard/ae/README.md`. A mock of the AE scripting objects is the only way to dry-run the script here; AE itself is not available in the container, so Claude cannot write an .aep: the script downloads any missing clip itself (curl, URLs from clips.json via export.js) and saves a new project as `storyboard/ae/Tiff Animatic.aep` (never over an existing one). **Kit zip for the user (11 October):** `Tiff-AE/` with `START HERE.txt`, `fonts/` (static TTFs instanced from the Google Fonts variable fonts with fontTools; Overpass PS names fixed to `Overpass-*`), `storyboard/ae/` and the referenced renders plus `song.mp3`, no clips (28.5 MB; file uploads to the user are capped at 30 MB).
